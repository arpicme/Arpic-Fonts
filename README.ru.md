# Arpic Fonts — шрифты для бионического чтения

[English](README.md) | **Русский**

**Arpic Sans** и **Arpic Serif** — шрифты с открытой лицензией для бионического чтения. Они автоматически выделяют начало каждого слова жирным начертанием, помогая глазам быстрее цепляться за текст и удерживать фокус.

Выделение работает нативно на уровне самого шрифта через OpenType-фичу `calt` (*Contextual Alternates*) — без расширений браузера, плагинов и скриптов.

## Состав

| Шрифт | Файл | Тип | Контраст |
| :--- | :--- | :--- | :--- |
| **Arpic Sans** | `Arpic-Sans.ttf` | Гротеск (без засечек) | Medeo Sans Display Regular + Bold |
| **Arpic Serif** | `Arpic-Serif.ttf` | Антиква (с засечками) | Medeo Serif Regular + Auto-Bold |

## Особенности

* **Полная поддержка кириллицы и латиницы** — корректно работает с русским языком (включая `Ё`, `Й` и расширенную кириллицу), английским и европейской диакритикой (в `Arpic Sans` также поддерживается греческий).
* **Высокий контраст** — чёткое разделение между обычной и жирной частью слова.
* **Корректные границы слов** — в `Arpic Sans` отключены буквенные лигатуры `ff / fi / fl`, чтобы выделение не ломало стыки букв в английских словах.
* **Никаких зависимостей** — достаточно просто установить `.ttf`-файл.

## Логика выделения

Количество жирных букв зависит от длины слова:

| Длина слова | Выделяется букв | Пример |
| :--- | :--- | :--- |
| 1–3 буквы | 1 | **в**, **н**а, **д**ля |
| 4–5 букв | 2 | **эт**ом, **сл**ова |
| 6–7 букв | 3 | **чте**ние, **шри**фте |
| 8–9 букв | 4 | **помо**гает, **выде**лены |
| 10–12 букв | 5 | **биони**ческое, **начер**танием |
| 13+ букв | 6 | **програ**ммирование |

## Установка и использование

1. Скачайте `.ttf`-файлы из репозитория (или со страницы **Releases**).
2. Установите их в систему (Windows, macOS, Linux) или скопируйте в папку шрифтов вашей читалки.
3. Выберите **Arpic Sans** или **Arpic Serif** в настройках приложения.

> **Примечание:** фича `calt` (*Contextual Alternates*) включена по умолчанию в современных браузерах, ОС, Microsoft Word и продвинутых читалках (например, KOReader). Если в вашем приложении выделение не появилось сразу, включите в его настройках шрифта **Контекстные альтернативы / Лигатуры / OpenType**.
